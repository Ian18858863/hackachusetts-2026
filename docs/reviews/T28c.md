## Review

**Verdict: REVIEWED.** No blocker; the two should-fix items below should be fixed before the demo.

1. **should-fix**: in Spanish and French, the "not present" count `{m}` does not change between singular and plural; only `n` uses `pick`. The primary demo case demo-npc1 has 1 not-present feature, so it shows "12 rasgos presentes y 1 no presentes" and "…et 1 absentes", which is ungrammatical, and it is in the main demo. Location: `ranking.ts:441-442, 548` (es) and `ranking.ts:714-715, 823` (fr). Fix: split out One/Other keys by `m`.
2. **should-fix**: the same plural problem, `altContradicted` is wrong when n=1 (es `ranking.ts:525`, fr `ranking.ts:798`). The English original is not correct for singular either, but the English must stay byte-for-byte unchanged, so fix only es and fr.
3. **nit**: `leadAllOne` in es (`ranking.ts:499`) and fr (`ranking.ts:772`) reads "(1 de 1)" and "(1 sur 1)", which is stiff; a natural singular sentence would do.
4. **nit**: several wordings could be more natural:
   - fr `closestOverlap` (`ranking.ts:770`): "le plus proche" is a literal translation; suggest "Recoupement le plus fort".
   - fr `statusRanked` (`ranking.ts:721`): "sur {counts}"; suggest "à partir de {counts}".
   - ja `overlapPartial` (`ranking.ts:349`): "重なりが一部" is unnatural; suggest "一部重なる".
   - ko `viaAncestorNamed*` fixes the particle as "를", while the rest of the file uses "을(를)"; inconsistent.
