Fix, one of two: remove `@context7` from `allowedTools` so every call needs confirmation; or open a separate claim to change `prompt` (not an MCP field, outside this task's scope) to state that queries may contain only library names and technical questions.

If the intent was to give it only to `rdd-builder`, the agent-level declaration from finding 1 narrows the scope. If it is intended for all sessions, say so clearly in the usage record.
