# Team context

- Three people work in this repo at the same time. Shared context, rules and open decisions live in `BRIEFING.md` at the repo root. Read it before starting any task, and update it when a decision changes.
- Do not assume what your human owns; check section 6 of `BRIEFING.md`.
- All project code must be written with Kiro. `.kiro/` stays committed and is never gitignored.
- Write project files (code comments, README, specs, UI copy, commit messages) in English.
- Pull/Sync before starting; small commits; push often; never force-push or delete others' work.
- Never commit secrets; use `.env`.
- When you use a Kiro feature in a new way, add one line to `docs/KIRO_USAGE.md`.
